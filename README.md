# Neon Junction Prototype

A tiny browser-playable top-down cyber-driving prototype.

## Play

Open `index.html` or serve the folder with any static server.

Controls:

- `WASD` or arrow keys to drive
- Touch buttons appear on coarse pointer devices

## Prototype Loop

1. Collect plasma crates around Neon Junction.
2. Deliver three crates to the garage.
3. Hack the relay terminals.
4. Escape through the east exit while drones chase you.

## Deploy

The repository includes a GitHub Pages workflow that deploys the static files from the repository root.
