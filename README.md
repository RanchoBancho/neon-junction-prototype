# Top Down Racing Prototype

A tiny browser-playable top-down racing prototype built from CraftPix racing assets.

## Play

Open `index.html` or serve the folder with any static server.

Controls:

- `WASD` or arrow keys to drive
- Drag the touch joypad on mobile
- `1`, `2`, `3` switch tracks
- `R` restarts the race

## Prototype Loop

1. Race three AI opponents.
2. Complete laps through checkpoint gates.
3. Use boost pads, avoid oil, recover with repair pickups.
4. Try the three tracks from the selector.

## Assets

Uses local CraftPix free racing assets. See the source package license text in the workspace or CraftPix license page: https://craftpix.net/file-licenses/

## Deploy

The repository includes a GitHub Pages workflow that deploys the static files from the repository root.
